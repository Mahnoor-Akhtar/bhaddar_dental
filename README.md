# DentalCareByDrawais

Modern, patient-centered dental practice web application for Dr. Awais Farooq Ch.

## Tech Stack
- **Frontend**: React, TypeScript, Vite, Custom CSS Design Tokens, Lucide Icons, Swiper
- **Backend**: Express, Node.js
- **Package Manager**: pnpm

## Development
```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```
